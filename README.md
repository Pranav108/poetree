# Poetree website

A standalone static landing page for Poetree. It uses plain HTML, CSS, and JavaScript, with no build step or runtime dependencies.

Open `index.html` directly or serve this folder with any static web server. For a local preview, run `python3 -m http.server 8000` from this folder and visit `http://localhost:8000`.

The images in `assets/` come from the supplied Poetree artwork, app icon, and app screenshots. The page intentionally shows “Coming soon” because no public App Store URL is available yet. Replace those labels with a real store link when one is ready.
